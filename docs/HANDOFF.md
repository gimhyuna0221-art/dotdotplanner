## 3. 최근 완료된 수정

### 3.1 저장 실패 배너 독립화

대상별 독립 키:

- items
- monthlyItems
- groups
- projects
- preferences
- weeklyPanelPrefs
- indexeddb

한 대상의 저장 성공이 다른 대상의 실패 배너를 지우지 않는다.  
같은 대상이 다시 성공할 때만 해당 배너가 사라진다.

### 3.2 프로젝트 백업 통합

- `exportAllDataAsJson()`에 `projects: state.projects`
- `backupBeforeMigration()`에 `projects: safeGet(PROJECTS_KEY)`

실제 Blob과 마이그레이션 경로로 검증했다.

### 3.3 Monthly Log 상단 정리

- `<h1 class="monthly-log-title">Monthly log</h1>` 제거
- 사용하지 않는 CSS 제거
- 헤더 상단 padding 32px → 20px
- 월 제목과 우측 아이콘 상향

### 3.4 입력창 중앙 정렬

최종 CSS 우선순위까지 확인해 다음 입력창을 중앙 정렬했다.

- 단일 선택
- 가로 범위
- 세로 범위
- 대각선 범위
- bottom-right 앵커

### 3.5 하드 스냅

`resolveMonthlyLogScheduleSnappedColumnAtPoint(el, x, previousColumn)`

- `Math.floor` 제거
- `Math.round`
- 이전 열 전달
- 0.15 데드존 히스테리시스
- 경계 부근 떨림 방지
- 자유 이동이 아닌 셀 단위 실시간 이동

### 3.6 마퀴 자동 스크롤 좌표계 수정

기존 결함:

- 시작점 `ds.startY`는 뷰포트 고정
- 일정 세그먼트는 자동 스크롤과 함께 이동
- 서로 다른 좌표계 때문에 감싼 일정이 선택에서 빠짐

수정:

- pointerdown에서 `scrollAnchorTop` 저장
- `scrollDelta` 계산
- `startYAdjusted = ds.startY - scrollDelta`
- 마퀴 시작점을 콘텐츠 이동량과 동기화

## 6. 사용자 수동 재검증

자동 테스트가 있어도 다음은 실제 조작 확인을 남겨 둔다.

### Monthly Log 입력

- 날짜 숫자·요일 라벨 한 번 클릭
- 해당 날짜 선택
- 입력창 즉시 포커스
- 아래→위·위→아래 범위 모두 입력창이 아래쪽 날짜에 표시
- Shift+휠로 셀 너비를 키웠을 때 입력창 잘림 없음
- 음력 ON 상태 날짜 선택
- 종료일 첫 클릭 직후 휠 조작

### Today·Weekly

- Today 같은 목록 3회 연속 재정렬
- Weekly 8·9·10·13·14일 균형 배치
- 네 화면 완료 메뉴 문구·체크 디자인 통일

### 연결·휴지통

- 3개 이상 연결 인스턴스 프로젝트 동기화
- 연결 monthlyItem 프로젝트 삭제·색 변경 즉시 반영
- 연결 인스턴스 전체 휴지통 이동·복원
- 다중 선택 + 그룹 + Monthly Log 복합 조작
- `instanceGroupId` monthlyItem 지난달 이월·삭제

### 실환경

- 실제 휴대전화 터치 스크롤·드래그
- 실제 동영상
- 대용량 이미지·동영상
- 4장 이상 이미지 묶음
- 실제 저장 용량 초과
- 실제 브라우저 두 탭 충돌 흐름

## 7. 설계 보류

### 7.1 Monthly Log 24시간 축

현재 18칸은 시간과 무관한 임의 레인이다.

결정 필요:

1. 기존 18칸 보기와 24시간 보기를 병존할지
2. 시간 없는 일정의 종일·시간 미정 트랙
3. 다일 일정을 연속 구간 또는 매일 반복으로 볼지
4. 자정 넘김을 지원할지
5. 기존 18칸 데이터를 어떻게 보존할지
6. 고정 시간 경계 23개와 자유 구분선을 어떻게 함께 표시할지

기존 권장안:

- 18칸 보기 유지
- 24시간 보기 별도 토글
- 시간이 없는 일정은 상단 별도 트랙
- 1차에서는 다일 일정을 매일 같은 시간대로 처리
- 자정 넘김은 2차 데이터 모델 논의

아직 코드 변경 없음.

### 7.2 백업·가져오기

- JSON 가져오기
- IndexedDB 첨부 포함 ZIP 백업
- 덮어쓰기·병합
- ID 충돌
- 연결 참조 충돌

정책 확정 전 구현 금지.

### 7.3 기타 정책

- 3개월 이상 누적 미완료
- 열별 개별 너비
- AM/PM 없이 `9` 입력
- 프로젝트 전용 화면
- 태그·검색·필터
