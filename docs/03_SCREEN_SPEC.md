# 03. 화면 명세 — DotDotPlanner

최종 업데이트: 2026-07-31  
문서 역할: 현재 화면에 무엇이 보이고, 조작하면 어떻게 동작해야 하며, 무엇을 합격으로 보는지 정의한다.

---

## 1. 전체 셸

### 기본 구조

```text
┌──────── 사이드바 ────────┬──────────── 메인 화면 ────────────┐
│ 오늘                     │ Today / Calendar / Trash           │
│ 달력                     │                                    │
│ 루틴*                    │ 상세 패널·설정 메뉴·팝업            │
│ 단축키*                  │                                    │
│ 검색*                    │                                    │
│ 휴지통                   │                                    │
│ 통계*                    │                                    │
│ 설정*                    │                                    │
└──────────────────────────┴────────────────────────────────────┘
```

`*` 표시 항목은 시각적 자리와 아이콘이 있어도 기능 연결이 완료되지 않았을 수 있다.  
현재 실제 화면 전환이 확정된 것은 `오늘`, `달력`, `휴지통`이다.

### 공통 원칙

- 데스크톱 웹 우선
- 메인 artboard 최대 폭 1625px
- 좁은 화면에서 구성 요소가 잘리거나 문서 전체 스크롤로 합쳐지지 않아야 함
- 라이트·다크 테마
- 보라색은 선택·포커스·강조
- 일요일·토요일 관례색
- 주요 입력과 주요 조작을 호버에만 숨기지 않음
- 화면 전환 시 선택 상태가 다른 화면으로 새지 않음

## 2. Today 화면

### 2.1 상단 영역

Today 상단은 다음 두 영역으로 구성된다.

1. 미니 달력
2. Daily 목록

미니 달력에서 날짜를 선택하면 Daily의 기준 날짜가 바뀐다.

### 2.2 Daily 빠른 입력

- 타입: 할 일·일정·메모
- Enter 저장
- 공백만 입력하면 생성하지 않음
- IME 조합 중 Enter 중복 생성 방지
- 현재 선택 날짜에 생성
- 날짜 범위 초안과 시간 초안이 있으면 생성 시 소비
- 생성 후 입력 상태를 정상 초기화

### 2.3 Daily 목록

항목은 상세형으로 표시한다.

지원:

- 완료 토글
- 완료 숨기기
- 완료한 할 일 정리
- 제목·상세 열기
- 단일·Shift 범위·Ctrl 비연속·Ctrl+Shift 범위 선택
- Ctrl/Cmd+A
- 그룹 생성·해제
- 복사·잘라내기·붙여넣기
- 연결 복사·연결 해제
- Delete 소프트 삭제
- 드래그 정렬과 날짜 이동
- Undo/Redo

Today 같은 목록에서 반복 재정렬할 때 항목이 자기 자리 위로 튀었다 돌아오는 FLIP 회귀가 없어야 한다.

### 2.4 이월

- 완료하지 않은 과거 할 일을 별도 접이식 영역으로 표시
- 완료 항목 제외
- 다일 할 일은 종료일 이후에만 대상
- 원 날짜·이월 이력 유지
- Weekly 일반 목록에 자동 이월 항목이 중복 표시되지 않음

### 2.5 Today의 이달의 할 일 패널

우측 상단 토글로 연다.

- Calendar 우측 패널과 같은 `monthlyItems` 사용
- 넓은 화면에서는 artboard 바깥 여유 공간에 도킹
- 여유가 부족하면 overlay
- 도킹 시 backdrop 없음
- overlay 시 backdrop 클릭으로 닫기
- 메인 artboard 폭과 Weekly 배치를 밀어내지 않음
- 월간 항목 생성·완료·유형 변경·상세·삭제
- 지난달 미완료 접이식 영역
- 완료 숨기기와 완료 정리

## 3. Weekly 화면

Weekly는 Today 화면 하단 패널이다.

### 3.1 날짜 범위

- 표시 일수 1~14
- 1~7일: 한 행
- 8~14일: 두 행
- 날짜 수를 최대한 균형 있게 분배
  - 8일 = 4+4
  - 9일 = 5+4
  - 10일 = 5+5
  - 13일 = 7+6
  - 14일 = 7+7

### 3.2 두 행

- 각 행 독립 스크롤
- 중앙 분할선으로 높이 비율 조절
- 비율 저장
- 한 행 보기에서는 분할선 비활성

### 3.3 항목 조작

- 날짜 열 안에서 인라인 생성
- Daily와 같은 항목 선택 모델
- Daily↔Weekly 드래그
- 다중 선택 이동
- 그룹
- 완료·숨기기·정리
- 복사·붙여넣기
- 휴지통 복원 대상 날짜
- 표시 범위 전체에 완료 메뉴 적용

### 3.4 패널 자체

- 위쪽 경계를 드래그해 높이 조절
- 접힌 상태는 내부 크기를 파괴하지 않고 transform으로 아래로 이동
- 다시 펼치면 마지막 높이 복원
- Weekly 내부 스크롤이 상단 문서 스크롤과 합쳐지지 않음

## 4. Calendar / Monthly Log 화면

Calendar 화면은 다음 구조다.

```text
┌──────── Monthly Log 31일 격자 ────────┬─ 경계선 ─┬─ 이달의 할 일 ─┐
│ 날짜 라벨 + 일정 18칸                  │ 드래그    │ monthlyItems    │
└────────────────────────────────────────┴───────────┴────────────────┘
```

### 4.1 헤더

- `YYYY년 M월 달력`
- 이전 달
- 이번 달
- 다음 달
- 설정 메뉴
- 불필요한 `Monthly log` 영문 제목은 표시하지 않음

### 4.2 기본 격자

- 월의 실제 날짜 수만큼 세로 행
- 가로 18칸
- 18칸은 현재 **시간이 아닌 임의 레인**
- 하루 일정은 한 행의 사각 블록
- 다일 일정은 여러 날짜를 관통하는 블록
- 하루 일정 제목 가로
- 다일 일정 제목 세로
- 제목은 블록 내부 중앙
- 프로젝트가 있으면 프로젝트 색 우선
- 연결 일정은 같은 색과 연결선 사용
- 비연결 인접 일정은 색 충돌 회피

### 4.3 일정 생성

#### 단일 셀

빈 셀 클릭:

- 정확히 한 셀 선택 오버레이
- 입력창 중앙 정렬
- Enter로 일정 생성

#### 범위

드래그 방향과 무관하게 직사각형 범위를 정규화한다.

- 가로
- 세로
- 대각선
- 위→아래
- 아래→위

입력창은 정규화된 범위의 아래쪽 날짜를 앵커로 사용한다.

기존 일정과 충돌하기 전까지 입력 오버레이를 확장한다.

### 4.4 마퀴 선택

드래그 사각형이 기존 일정과 겹치면 생성이 아니라 기존 일정 마퀴 선택으로 전환한다.

요구 동작:

- 현재 사각형과 기존 일정의 겹침 여부를 포인터 이동마다 재판정
- 빈 영역으로 돌아오면 생성 모드 복귀 가능
- 서로 다른 날짜 행의 여러 일정 선택
- 범위 밖 일정 제외
- 자동 스크롤 중에도 시작점이 콘텐츠와 함께 이동
- 하드코딩 픽셀이 아니라 실제 DOM rect를 기준으로 검증

### 4.5 하드 스냅

사용자가 말하는 스냅은 드롭 후 위치 보정이 아니다.

> 드래그 미리보기 자체가 자유 이동하지 않고, 셀 경계를 충분히 넘을 때만 칸에서 칸으로 이동해야 한다.

열 판정:

- `Math.round`
- 이전 스냅 열 사용
- 0.15 데드존 히스테리시스
- 경계 부근 떨림 금지
- 행·열 판정이 잠시 끊겨도 마지막 스냅 위치 유지

### 4.6 크기 조절

- Ctrl+휠: 날짜 행 높이
- Shift+휠: 전역 셀 너비
- 최소·최대 제한
- 일정 없는 날짜 행은 사용자 지정 높이 자동 초기화
- 메뉴:
  - 날짜칸 전체 초기화
  - 높이 초기화
  - 너비 초기화

현재 셀 너비는 전역 값이다. 열별 개별 너비는 미구현이다.

### 4.7 음력

- 음력 ON/OFF
- 음력 텍스트는 절대 위치
- 행 높이·셀 좌표를 밀지 않음
- 음력 월 1일과 주요 음력 공휴일 중심의 축약 표시
- 숨겨진 날짜도 접근성 라벨에는 음력 정보 유지 가능

### 4.8 구분선

- 날짜 행 안의 자유 세로 구분선
- 추가·제거
- 격자 스냅
- 현재 최대 6개
- 패널 폭 조절 경계선과는 별개

### 4.9 완료 메뉴

- 완료 항목 숨기기
- 완료한 할 일 정리하기
- 숨기기는 데이터 삭제가 아니라 표시 상태
- 설정 저장

### 4.10 24시간 축

아직 구현하지 않는다.

미결정:

- 18칸 보기와 병존 여부
- 종일·시간 미정 트랙
- 다일 시간 일정의 의미
- 자정 넘김
- 기존 18칸 데이터 보존
- 23개 고정 시간 경계
- 자유 구분선과 시간 경계 공존

## 5. 이달의 할 일

Calendar 우측과 Today 패널은 같은 기능을 공유한다.

### 기본 동작

- 날짜 없이 월 단위로 생성
- 할 일·일정·메모·구분선
- 완료
- 제목·유형·상세·프로젝트
- 그룹
- 정렬
- 복사·붙여넣기
- 날짜에 배치
- 마스터는 유지하고 배치본 생성
- 배치본과 공유 필드 동기화

### 지난달 미완료

- 바로 전 달의 미완료 마스터 표시
- 완료·삭제·배치본 제외
- `[이번 달]`: 같은 ID의 `monthKey` 이동
- `[삭제]`: 휴지통
- 마지막 항목 처리 후 영역 즉시 제거

3개월 이상 누적 정책은 보류한다.

## 8. 선택과 단축키

### 항목 선택

- 클릭: 단일
- Shift: 범위 교체
- Ctrl/Cmd: 비연속 토글
- Ctrl/Cmd+Shift: 범위 추가
- Ctrl/Cmd+A: 활성 목록 전체
- Escape: 선택·팝업·입력 취소

### 그룹

- Ctrl/Cmd+[: 그룹 생성
- Ctrl/Cmd+]: 그룹 해제

### 일반 복사

- Ctrl/Cmd+C
- Ctrl/Cmd+X
- Ctrl/Cmd+V

### 연결 복사

- Ctrl/Cmd+Alt+C
- Ctrl/Cmd+Alt+V
- Ctrl/Cmd+Alt+U: 연결 해제

### 이력

- Ctrl/Cmd+Z
- Ctrl/Cmd+Shift+Z
- Ctrl/Cmd+Y

기본 텍스트 입력·브라우저 클립보드 동작을 항목 단축키가 가로채지 않아야 한다.

## 9. 반응형과 도킹

- 실제 artboard 오른쪽 여유 폭 측정
- 충분하면 도킹

## 10. 합격 기준

### 자동 검증 기준

- `node --check app.js`
- 대상 기능 Playwright 테스트
- 기존 회귀 스위트
- 콘솔 오류 0
- 페이지 오류 0
- DOM rect 기반 드래그 테스트
- Undo/Redo 전후 데이터 필드 검증
- 저장 payload 실제 내용 검증

현재 최신 누적 보고: `144/144` 통과.

### 사용자 수동 재검증

- 날짜 라벨 클릭과 입력 포커스
- 범위 선택 방향별 입력창 위치
- 확대 셀 입력창 레이아웃
- 음력 ON 상태 날짜 선택
- 종료일 첫 클릭 휠
- Today 연속 재정렬
- Weekly 특정 일수 균형 배치
- 실제 휴대전화 터치
- 연결 인스턴스 복합 조작
- 동영상·대용량 첨부
- 실제 저장 용량 초과

자동 테스트 결과와 실제 조작 감각을 같은 완료 표시로 합치지 않는다.
